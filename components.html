Hardware Functions and Compatibility

How the main parts work together.

Major component relationships

What each part does

  • Motherboard: the main circuit board that connects all parts.
  • CPU: processes instructions.
  • RAM: holds data in use right now.
  • Storage: keeps files when power is off.
  • GPU: draws images for the display.
  • PSU: converts wall power into low voltages for components.

Device types

Input

Keyboard, mouse, webcam.

Output

Monitor, speakers, printer.

Processing

CPU, GPU.

Storage

HDD, SSD, USB flash drive.

Internal hardware sits inside the case (motherboard, RAM, drives). External hardware connects by cable or wirelessly (monitor, keyboard, printer).

Compatibility checklist

  • CPU socket: the CPU must fit the motherboard socket and be supported by its chipset and BIOS version.
  • RAM type: for example DDR4 and DDR5 are not interchangeable.
  • Storage interface: SATA, M.2 or NVMe must be supported by the board.
  • Physical size: check case, motherboard form factor, GPU length and cooler height.
  • Power: the PSU needs enough wattage and the right connectors.

Always confirm exact specifications in the manufacturer's manual.
